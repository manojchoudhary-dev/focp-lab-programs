# FOCP Lab Programs (C)

Fundamentals of Computer Programming (CSE-1003) — lab programs from my B.Tech CSE (Core), Semester 1 at IIIT Bhopal. 64 programs across Labs 1–8, organised lab-wise below.

## Run any program

```bash
gcc lab-01/p01-sum-of-two-numbers.c -o program
./program
```
