# FOCP Lab Programs (C)

Fundamentals of Computer Programming (CSE-1003) — lab programs from my B.Tech CSE (Core), Semester 1 at IIIT Bhopal.

64 programs across Labs 1–8. Every program takes input from the user wherever the question allows, and each file carries its sample input and output in the header comment. All programs compile cleanly with GCC.

## Run any program

```bash
gcc lab-01/p01-sum-of-two-numbers.c -o program
./program
```
