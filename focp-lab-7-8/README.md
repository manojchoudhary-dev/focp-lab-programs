# FOCP Lab Assignments 7 & 8 — Solved Programs

Fundamentals of C Programming (1003), IIIT Bhopal — CSE Core, Semester 1.
All programs compiled with gcc (-std=c99 -Wall) and run-verified on sample inputs (see verified_outputs.json).

## Lab 7 (arrays, matrix, functions)
1. 01_prime_elements_in_array.c — prime elements in an array
2. 02_row_column_sum_matrix.c — sum of each row & column of MxN matrix
3. 03_linear_search_matrix.c — linear search in matrix, all occurrences
4. 04_marks_total_percentage_grade.c — 5 subjects: total, percentage, grade
5. 05_primes_1_to_n.c — all prime numbers from 1 to n
6. 06_factors_using_function.c — factors of a number via user-defined function

## Lab 8 (strings, structures)
1. 01_compare_strings_strcmp.c — compare two strings with strcmp (fgets used instead of gets, which modern compilers reject)
2. 02_structure_putdata.c — structure initialized at declaration, printed via putdata()
3. 03_string_palindrome.c — string palindrome check
4. 04_toggle_case.c — swap case of every letter

Files: lab-07/ and lab-08/ (.c sources), focp-lab-7-8-programs.pdf (programs + outputs), focp-lab-7-8.zip (ready to add to the focp-lab-programs GitHub repo).
